# ICAV Time Tracker - App Store Materials

This directory contains all the necessary materials for publishing ICAV Time Tracker on the iOS App Store and Google Play Store.

## 📁 File Structure

```
App Store Materials/
├── App Description.md          # Complete app description for App Store
├── Promotional Text.md         # Marketing copy and keywords
├── Privacy Policy.md           # Privacy policy for legal compliance
├── Support Page.md             # Support documentation
└── README.md                   # This file
```

## 🚀 How to Use These Materials

### 1. App Store Description
- **File**: `App Description.md`
- **Use**: Copy the content into your App Store listing
- **Customize**: Update any company-specific information
- **Length**: Optimized for App Store character limits

### 2. Promotional Text
- **File**: `Promotional Text.md`
- **Use**: Marketing copy for app store optimization
- **Includes**: Keywords, taglines, screenshot text, and value propositions
- **Customize**: Adjust keywords and messaging for your target audience

### 3. Privacy Policy
- **File**: `Privacy Policy.md`
- **Use**: Required for App Store submission
- **Customize**: 
  - Replace `[Current Date]` with actual dates

  - Review and modify as needed for your specific data practices
- **Host**: Can be hosted on GitHub Pages or your website

### 4. Support Page
- **File**: `Support Page.md`
- **Use**: Customer support documentation
- **Customize**: 
  - Update contact information
  - Modify features based on your implementation
  - Add company-specific procedures
- **Host**: Can be hosted on GitHub Pages or your website

## 📱 App Store Submission Checklist

### Legal Requirements
- [ ] Privacy policy compliant with App Store guidelines
- [ ] Terms of service (if applicable)

### Technical Requirements
- [ ] App binary ready for submission

## 🌐 Hosting Options

### GitHub Pages (Recommended)
1. Create a new repository for your app store materials
2. Upload these files to the repository
3. Enable GitHub Pages in repository settings
4. Use the generated URL for your privacy policy and support links

### Example GitHub Pages Setup
```bash
# Create new repository
git init app-store-materials
cd app-store-materials

# Add files
cp -r "App Store Materials/" .

# Commit and push
git add .
git commit -m "Add app store materials"
git remote add origin https://github.com/yourusername/icav-app-store.git
git push -u origin main

# Enable GitHub Pages in repository settings
# Use URL: https://yourusername.github.io/icav-app-store/
```
